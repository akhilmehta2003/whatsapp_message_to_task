Feature Flow
1
Long-press message — Context menu appears with emoji reactions + action items including the new "Create Task" option
2
AI pre-fills task name — The message text is parsed to extract the task. User can edit before saving
3
Set due date + reminder — Suggested values auto-filled (Friday detected from message), user can override
4
Task pinned to chat — A task chip appears in the chat thread linking back to the task for easy access
5
My Tasks section — New bottom nav tab shows all tasks from all chats with filter, complete, and reminder controls
Design Decisions
✦
Zero friction — "Create Task" is integrated into the existing long-press context menu, no new gestures needed
✦
AI parsing — Message text is automatically parsed to suggest task name, due date, and priority
✦
In-chat visibility — Task chip in chat thread means users never lose context of where a task came from
